# Vince Joel Enriquez — QA Tester Portfolio

A one-page portfolio introducing my experience, QA workflow, selected projects, skills, credentials, and contact details.

## Features

- Scroll-driven portfolio sections with animated transitions
- Procedural 3D centerpiece and background effects powered by Three.js
- Responsive layout for desktop and mobile
- Reduced-motion styling for visitors who prefer less animation
- Links to selected projects and professional profiles

## Built with

- HTML, CSS, and JavaScript
- [Three.js](https://threejs.org/) for WebGL graphics
- [Inter](https://fonts.google.com/specimen/Inter) and [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) via Google Fonts

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Keep an internet connection available so the page can load Three.js and the Google Fonts stylesheet from their CDNs.

## Publish with GitHub Pages

1. Put the portfolio HTML file in the repository root and name it `index.html`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Open the Pages URL shown in the settings after deployment finishes.

GitHub's repository file preview shows the source code. Open the GitHub Pages URL to view the portfolio as a website and run its animations.
